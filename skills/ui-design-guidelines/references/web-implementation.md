# Web 下的一种实现示例

本文件是 `ui-design-guidelines` 的按需参考:仅当项目使用 Web/CSS 技术栈、需要把规范落地成具体写法时才读取;其他技术栈按各自能力实现 SKILL.md 里的视觉结果即可,不必读取,以免带入无关上下文。

以下内容只是 Web 场景里达成上述视觉结果的一种对应,不是规范条款、也不参与交付核对。

- 等宽数字:给会变动的数值加 `font-variant-numeric: tabular-nums`;本身使用等宽字族的元素天然满足,不必重复声明。
- 同心圆角:用 `border-radius` 按 `outer = inner + padding` 取值,例如外层 16px、内边距 12px,内层取 4px。
- 标题平衡换行:多行短标题用 `text-wrap: balance`,长段落不必加。
- 柔和阴影替代边框:优先用多层柔和 `box-shadow`(低透明度、大模糊半径);项目有阴影或分隔线设计令牌时直接复用;需要保底轮廓时用 `color-mix()` 把分隔线色调淡或低不透明度的 1px 线,而不是实色 1px 线。
