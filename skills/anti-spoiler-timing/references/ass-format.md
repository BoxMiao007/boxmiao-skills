# ASS 字段与占位格式

## Dialogue 字段顺序

`[Events]` 段的 `Format:` 行定义字段顺序，脚本按固定 9 个前导字段解析（ASS 标准顺序）：

```
Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text
```

`generate` 会**严格校验**这几个字段的顺序，不符就 fail-closed 报错。原因：如果顺序不同（比如正文被放进 Style 字段），继续解析会把剧情文字当成字段原样写进占位稿，直接击穿防剧透。

`Text` 可以包含逗号，因此按**第 9 个逗号**切分，后面的全部算 Text。`parseDialogue` 遵循这一点。

时间格式 `H:MM:SS.cc`（支持 1–3 位小数），解析为毫秒用于 CPS 与碰撞判断。

## ID token

```
[[AS:0007:a1b2c3de|M]]████████████████
└────── token ──────┘ └── 填充 ──┘
```

| 段 | 含义 |
|---|---|
| `AS` | 固定前缀，避免与正文里普通方括号冲突 |
| `0007` | Dialogue 序号（1 起，至少 4 位），不是物理行号。超过 9999 行时自然扩展为 5 位以上，无需改格式 |
| `a1b2c3de` | `sha256(内部零起行号 + U+0000 + 可见正文)` 前 8 位（内部行号从 0 开始，与显示的 1 起序号相差 1） |
| `M` | 长度档：S / M / L |
| `████` | 固定数量的 `█`，只表示档位，不泄露精确字数 |

ID 由内部行号与**剥掉标签后的可见正文**哈希得到：同一输入稳定；校轴人员改样式标签不会改变 ID。**在末尾**增删行时其他行 ID 不变；**在中间插入/删除行时，其后各行因行号位移会重新编号（ID 改变）**——所以校轴只能改时间/样式，不能增删台词行。

**注意**：这是普通哈希，不是加密。校轴人员若已有一条候选台词，可以用公开算法哈希后确认是否命中。因此不要把脚本和对照表交给校轴人员——这是流程约束，不是算法保证。

## 长度档阈值

按可见字符数（剥掉 `{...}` 后）计算：

| 档 | 字数范围 | 填充块数 |
|---|---|---|
| S | ≤ 12 | 8 |
| M | 13–24 | 16 |
| L | ≥ 25 | 28 |

填充块数按档**固定**，不随真实字数变化，避免泄露精确长度。L 档无上界。改阈值时同步改 `scripts/lib.mjs` 的 `sizeOf` 与 `FILL`。

## 标签白名单

占位稿只保留这些定位/尺寸标签（校轴人员可调）：

- `\an1`–`\an9`：对齐（整数）
- `\pos(x,y)`：位置
- `\move(x1,y1,x2,y2[,t1,t2])`：移动
- `\fs<n>`、`\fscx<n>`、`\fscy<n>`：字号与缩放（`n` 支持有符号小数，如 `20.5`、`+5`、`-3`）
- `\fr`（=`\frz`）、`\frx`、`\fry`、`\frz`：旋转（角度支持有符号小数；裸 `\fr` 无数字时按非白名单处理，回填从原文恢复）
- `\fax`、`\fay`：倾斜（有符号小数）

以下标签**不进占位稿**（可能夹带字体名、样式名或绘图，泄露剧情）：`\fn`、`\r`、`\t(...)`、`\p`、`\clip`、`\iclip`、`\c`/`\1c` 等颜色标签。它们原样保存在 `mapping.json`，回填时从原文恢复。

## 可改与不可改

| 内容 | 占位稿 | 回稿可改 | 回填处理 |
|---|---|---|---|
| Layer / Start / End | 保留原值 | 可改（核心） | 以回稿为准 |
| Style / Name / Effect | 脱敏为 `AS1` / 空 | 可改 | 仍是占位值时还原原文，否则以回稿为准 |
| MarginL/R/V | 保留数字 | 可改 | 以回稿为准 |
| 行首定位标签 | 白名单保留 | 可改 | 以回稿为准 |
| 行首非定位标签 | 剥离 | — | 从原文恢复 |
| ID token | 必须存在 | **不可改**（含档位字母） | 变为译文正文 |
| `█` 填充 | 按档固定 | 不可删减 | 随 token 一起被替换 |
| 译文正文 | 不存在 | 不可新增 | 从对照表写回 |
| 注释（`;` / `Comment:`） | 全部删除 | — | 不恢复 |
| 原始样式定义 | 不出现 | — | 从 `mapping.originalStyles` 写回 |

## 防剧透自检

交付占位 ASS 前，做一次文本搜索确认没有泄漏：

- `mapping.json` 中任一 `entries[id].visible` 不应出现在占位 ASS 中。
- 原始 ASS 的 Title / Comments / Note / Style 名 / 角色名 / Effect 不应出现在占位 ASS 中。
- 占位 ASS 的每条 Dialogue 都应命中 `\[\[AS:\d{4,}:[0-9a-f]{8}\|[SML]\]\]`。
- 占位 ASS 的 Style 应只有 `AS1`，Name/Effect 应为空。

命中任意一条就停止交付，检查 `generate` 是否误用了原文 ASS 或不兼容的 ASS 格式。

## 剧透隐藏信道（依据 Aegisub 官方标签手册）

参考：https://aegisub.org/docs/latest/ass_tags/ —— 官方明确「override 块内无法识别的文本会被渲染器静默忽略，因此常被用作行内注释」。这意味着剧透不只能藏在译文正文里，还能藏在以下位置。占位稿生成时必须逐类堵住：

| 信道 | 例子 | 处理方式 |
|---|---|---|
| 字符串参数 | `{\fn凶手是张三}`、`{\r反派样式}` | 整个标签丢弃，只进 mapping |
| 变换容器 | `{\t(\fn凶手…)}`、嵌套 `\t(\t(...))` | 按平衡括号整体遮罩后丢弃 |
| 任意块的注释文本 | `{\i1 凶手是张三}`、`{\pos(1,2) 凶手姓名}` | 只提取白名单定位标签，其余字符丢弃（定位标签须以空白/反斜杠/结尾分隔；紧贴文字如 `{\pos(1,2)凶手姓名}` 属畸形写法，会整块丢弃） |
| 数值参数夹带 | `{\pos(凶手,2)}`、`{\move(1,2,凶手,4)}` | 参数限定为纯数字 `[-\d.,\s]+`，不匹配则整标签丢弃 |
| 矢量裁剪命令串 | `{\clip(1,m 0 0 l 凶手…)}` | 非矩形 clip 一律丢弃 |
| 绘图区间裸文本 | `{\p1}凶手文字{\p0}` | `\p` 区间内容随正文进 mapping，不进占位 |
| Script Info 值夹带 | `PlayResX: 1080 凶手是张三` | 按白名单键重建规范值，值不合规就丢弃整行 |
| 注释行 / Style / Name / Effect | `Comment:`、`;`、角色名、Effect | 全部删除或置空 |

**数值型标签**（`\bord \shad \blur \fs \fscx \fscy \fax \fay \fr*`、颜色 `\c&H…&`、alpha、卡拉 OK `\k` 系、`\an \q \fad \fade`、矩形 clip、`\p \pbo`）的参数不含人类可读文本，理论安全；但除白名单里的定位标签外，占位稿一律不保留，回填时从 mapping 原样恢复。

**fr 系列**：官方有 `\fr`（=`\frz`）、`\frx`、`\fry`、`\frz` 四种，角度可为负数/小数。白名单数值统一用 `POSITION_NUM = [-+]?(?:\d+(?:\.\d+)?|\.\d+)`（完整有符号小数）匹配，`fr` 组不再可选——早期版本会把 `\frz30` 截成 `\fr`、把 `\fs20.5` 截成 `\fs20` 而残留 `.5`，均已修复。裸 `\fr`（无角度）按非白名单处理，占位稿不显示、回填时从原文恢复。

## 支持范围与保真度限制

- **只支持 ASS v4.00+（`[V4+ Styles]`，23 字段样式）**。SSA v4 的 `[V4 Styles]`（18 字段）会被 `generate` 明确拒绝，请先在 Aegisub 另存为 v4.00+。
- **Dialogue 的 Actor/Name 字段不能含逗号**。ASS 的 `Dialogue:` 按逗号分字段，Name 含逗号会把 Margin 挤成文字；`generate` 会检测到非数字 Margin 并抛错，而不是静默错位。
- **`[Fonts]` / `[Graphics]`（内嵌字体/图形）不会写回 `final.ass`**。它们不随占位稿流转，`final.ass` 从占位稿重建，因此内嵌素材会丢失；若依赖内嵌字体，请在交付前用原 ASS 的 `[Fonts]` 段补回，或确保观看端已安装相应字体。
- **Script Info 只保留安全字段**：`PlayResX/Y`（数字）、`ScriptType`（`v4.00+`）、`WrapStyle`（0–3）、`ScaledBorderAndShadow`（yes/no）、`YCbCr Matrix`（仅真实矩阵名 `TV/PC.601/709/2020/240M/FCC`）、`LayoutResX/Y`（数字）、`Timer`（数字）。`Title`、`Video/Audio File`、`[Aegisub Project Garbage]` 等一律丢弃（可能含剧透/文件名提示）；字段值只要不符合上述严格格式就整行丢弃，防止把 `YCbCr Matrix: BOSSISDEAD` 这类 ASCII 剧透词带进占位稿。
- **尾部空白会被规范化**：每行 Text 末尾的空格/制表符会被去除，不影响显示，但会改变"逐字节"结果（真实 Aegisub 输出不会有尾随空白）。
