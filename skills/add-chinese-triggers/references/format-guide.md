# 格式参考

## 1. 同义词库

写中文意图时，用 `/` 把同一动作的常见说法并列，覆盖不同用户的叫法：

| 动作 | 并列写法 |
|---|---|
| 审查 | 审/评审·审阅·过一遍·挑毛病 |
| 排查 | 查/排查·定位·诊断·找根因 |
| 创建 | 写/建·做·画·生成 |
| 修改 | 改/调整·优化·重构 |
| 获取 | 抓/提取·拉·读 |
| 安装 | 找/装·引入·加上 |
| 配置 | 配/设置·初始化·接好 |
| 执行 | 跑/执行·触发·走一遍 |
| 追问 | 拷问/盘问·压力测试·反问 |
| 整理 | 梳理/统一·归纳·理清 |

经验：**2~5 个就够**。再多是在堆 token，收益递减。

## 2. token 实测

对 22 个真实 skill 的 description 实测（`tiktoken`，`o200k_base` / `cl100k_base`）：

| 版本 | o200k | cl100k |
|---|---:|---:|
| 原始英文 | 1,180 | 1,181 |
| 列举式（`当用户…时使用。中文触发词包括：A、B、C。`） | 2,841 | 3,356 |
| **意图式（`…A/B/C时使用。`）** | **1,649** | **1,778** |

意图式比列举式**少花 72% 的增量**，同时覆盖更多说法。

量法（没装 tiktoken 就先 `pip install tiktoken`）：

```python
import tiktoken, yaml, re, os
enc = tiktoken.get_encoding("o200k_base")
def desc(p):
    L = open(p, encoding="utf-8").read().split("\n")
    end = next(i for i in range(1, len(L)) if L[i].strip() == "---")
    d = (yaml.safe_load("\n".join(L[1:end])) or {}).get("description")
    return re.sub(r"\s+", " ", str(d or "")).strip()
for d in sorted(os.listdir(".")):
    p = os.path.join(d, "SKILL.md")
    if os.path.isfile(p):
        print(f"{len(enc.encode(desc(p))):5d}  {d}")
```

## 3. 回归评测设计（改了几十个 skill 时做）

追加中文是为了"更容易被触发"，那就得证明没把触发搞坏。两个用例集：

**基础集**：每个 skill 写 3 条正例，刻意用三种说法——
1. 纯口语、不带英文术语（`帮我画个思维导图，节点之间要能连线`）
2. 带技术名词（`建一个 .canvas 文件`）
3. 简短模糊（`这个模块的接口怎么切`）

再配一批反例（`把这段文字改成更正式的书面语`），期望返回 `none`。

**对抗集**：每条给 1~2 个 `distractors`（最容易误吸的邻居）和一句 `why`（判定依据）。示例：
"帮我给这个 PR 写一段正文"：正确应是「写 PR 正文」那个 skill，干扰项是「审 PR 改动」那个，判定依据是"产出物是 PR body，不是审改动"。

跑法：把 `<name> + <description>` 拼成 catalog，让被测模型对每条请求只选一个 skill 或 `none`，按 `expect` 打分。
**同一个作答者、同一批题，改动前后各跑一次**才有可比性。

一个实测事实（别踩坑）：强模型对英文原版 description 也能正确路由中文请求，所以**这套评测往往测不出中文带来的分数提升**——它的真实价值是**回归护栏**（改坏了立刻掉分）和**抓弱路由**（纯字面匹配的笨路由器在这套题上只有 66%）。

## 4. 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 把英文翻译成中文 | 破坏原文、与原意漂移 | 英文一字不动，只在后面追加 |
| 写 `中文：` 前缀 | 每个 skill 白花 2~3 token | 直接 `…时使用。` |
| 列举用户原话 | 贵，且换个说法就漏 | 写意图 + 同义词 |
| 中文里用 ASCII 冒号+空格 | YAML 直接解析失败 | 用全角 `：` |
| 把 `deepening opportunities` 写成"重构" | 范围变大，容易误触发 | 忠实原意，用"加深模块的机会" |
| 手改 YAML | 引号/折叠块容易被改坏 | 用 `scripts/apply_cn_triggers.py` |
| 没有 baseline 就宣称"没改坏" | 无法证明 | 动手前先快照，跑 `verify_descriptions.py --baseline` |
